# Rooted Ready - Downloads

This repository hosts the downloadable packs used by the Rooted Ready apps
(voices, voice samples, Piper, FFmpeg and fonts). The apps download what they
need automatically on first launch. You don't need to download anything here
by hand.

This is not open-source software.
